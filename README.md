# Task 4: Mobile-Friendly Website Using CSS Media Queries

## Objective
Convert a desktop-style page into a responsive website that works on phones, tablets, and desktop screens.

## Files
- `index.html` — sample website structure
- `style.css` — responsive styling and media queries

## How to run
1. Extract the ZIP file.
2. Open the `Task-4-Responsive-Website` folder in VS Code.
3. Open `index.html` in Chrome (or use the VS Code Live Server extension).
4. Press `F12` in Chrome to open DevTools.
5. Click the device toolbar icon (or press `Ctrl + Shift + M`).
6. Test common phone and tablet sizes.

## Responsive techniques used
- Mobile-first CSS defaults.
- Flexible widths and `max-width: 100%` for images.
- Flexbox navigation that wraps on narrow screens.
- CSS Grid columns that change at 600px and 900px.
- Font sizes using `clamp()`.
- Media query for very small phones (max-width: 380px).
- `box-sizing: border-box` to help prevent overflow.

## Deliverable
The updated CSS provides responsive layouts for mobile, tablet, and desktop viewports.
